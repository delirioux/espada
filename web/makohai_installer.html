Makohai

Generative tracker grooves for the M-VAVE FM-1, razor sharp

Connect the FM-1 directly to the computer with a USB data cable and press Install. Chrome or Edge on a computer; allow MIDI when the browser asks.

Do not unplug the cable or close this page while it writes.

Makohai is in development and was built for fun: it comes with no warranty. If the FM-1 misbehaves, return to the official firmware below, or install another firmware from the FM-1 Firmware Hub. Makohai keeps its own settings and patterns in flash: what another firmware saved there is not kept, so back it up first. If an install is cut off, press Install again: the FM-1 stays in update mode until it is finished. If Makohai does not start, hold OCT- while switching on: the USB rescue, where this page still reaches the FM-1. An FM-1 that no longer starts at all needs a Transporter.

Install a test build

A Makohai package from a test build (GitHub: Actions > the run > Artifacts > makohai-firmware, its .fwsc). It is checked here, in the browser, and not sent anywhere. Install above puts the published Makohai back.

Return to the official firmware (V15)

Get the official FM-1 V15 from M-VAVE and select its unmodified FM-1.fwsc. It is checked here, in the browser, and not sent anywhere. Makohai's saved settings and patterns are not kept.
